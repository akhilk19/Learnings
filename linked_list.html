Linked List Interview Masterclass

Comprehensive guide covering fundamentals, patterns, and every essential LeetCode problem from Easy to Hard.

1. The Core Java Node Structure

Every linked list problem starts with the basic node definition. Unlike arrays, elements are scattered in memory and connected solely by references (next):

public class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}

2. High-Frequency Interview Patterns

  • Fast & Slow Pointers (Tortoise and Hare): Used for finding cycles, middle elements, or cycle entry points.
  • Dummy / Sentinel Node: Simplifies edge cases where the head of the list might change or get deleted.
  • In-Place Reversal: Reversing full lists or sub-lists using a 3-pointer approach (prev, curr, next).
  • Merge & Two-Pointer Traversal: Combining sorted lists or aligning lengths to find intersections.

Easy Level Fundamentals

1. Reverse Linked List (LeetCode 206)

Easy
Input: 1 -> 2 -> 3 -> 4 -> 5 -> NULL
Output: 5 -> 4 -> 3 -> 2 -> 1 -> NULL

Detailed Approach: Maintain three pointers: prev (null), curr (head), and nextTemp. Iterate through the list, store the next node temporarily, reverse curr.next to point to prev, and shift forward.

public ListNode reverseList(ListNode head) {
    ListNode prev = null;
    ListNode curr = head;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}

2. Linked List Cycle (LeetCode 141)

Easy
Input: head = [3,2,0,-4], pos = 1
Output: true

Detailed Approach: Use Floyd's Tortoise and Hare algorithm. Initialize `slow` and `fast` at the head. Move `slow` by 1 step and `fast` by 2 steps. If they meet, a cycle exists.

public boolean hasCycle(ListNode head) {
    if (head == null || head.next == null) return false;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) return true;
    }
    return false;
}

3. Merge Two Sorted Lists (LeetCode 21)

Easy
Input: l1 = [1,2,4], l2 = [1,3,4]
Output: [1,1,2,3,4,4]

Detailed Approach: Use a dummy head node. Compare nodes from both lists and attach the smaller one to the result list iteratively until one list runs out, then attach the remaining nodes.

public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    ListNode dummy = new ListNode(0);
    ListNode curr = dummy;
    while (list1 != null && list2 != null) {
        if (list1.val <= list2.val) {
            curr.next = list1;
            list1 = list1.next;
        } else {
            curr.next = list2;
            list2 = list2.next;
        }
        curr = curr.next;
    }
    curr.next = (list1 != null) ? list1 : list2;
    return dummy.next;
}

4. Palindrome Linked List (LeetCode 234)

Easy
Input: [1,2,2,1]
Output: true

Detailed Approach: Find the middle of the linked list using fast/slow pointers, reverse the second half of the list, and compare values from the start and middle head.

public boolean isPalindrome(ListNode head) {
    if (head == null || head.next == null) return true;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode secondHalf = reverse(slow);
    ListNode firstHalf = head;
    while (secondHalf != null) {
        if (firstHalf.val != secondHalf.val) return false;
        firstHalf = firstHalf.next;
        secondHalf = secondHalf.next;
    }
    return true;
}
private ListNode reverse(ListNode head) {
    ListNode prev = null, curr = head;
    while (curr != null) {
        ListNode next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}

5. Remove Duplicates from Sorted List (LeetCode 83)

Easy
Input: [1,1,2,3,3]
Output: [1,2,3]

Detailed Approach: Traverse the sorted list. If `curr.val == curr.next.val`, bypass the duplicate node by pointing `curr.next` to `curr.next.next`. Otherwise, move `curr` forward.

public ListNode deleteDuplicates(ListNode head) {
    ListNode curr = head;
    while (curr != null && curr.next != null) {
        if (curr.val == curr.next.val) {
            curr.next = curr.next.next;
        } else {
            curr = curr.next;
        }
    }
    return head;
}

Medium Level Staples

6. Add Two Numbers (LeetCode 2)

Medium
Input: l1 = [2,4,3], l2 = [5,6,4]
Output: [7,0,8]

Detailed Approach: Traverse both lists simultaneously. Sum corresponding digits with any carry, store `sum % 10` in a new node, and carry forward `sum / 10`.

public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    ListNode dummyHead = new ListNode(0);
    ListNode current = dummyHead;
    int carry = 0;
    while (l1 != null || l2 != null || carry != 0) {
        int sum = carry;
        if (l1 != null) { sum += l1.val; l1 = l1.next; }
        if (l2 != null) { sum += l2.val; l2 = l2.next; }
        carry = sum / 10;
        current.next = new ListNode(sum % 10);
        current = current.next;
    }
    return dummyHead.next;
}

7. Remove Nth Node From End of List (LeetCode 19)

Medium
Input: head = [1,2,3,4,5], n = 2
Output: [1,2,3,5]

Detailed Approach: Advance a `fast` pointer by `n+1` steps. Move both `fast` and `slow` together until `fast` hits null, then update `slow.next = slow.next.next`.

public ListNode removeNthFromEnd(ListNode head, int n) {
    ListNode dummy = new ListNode(0, head);
    ListNode fast = dummy, slow = dummy;
    for (int i = 0; i <= n; i++) fast = fast.next;
    while (fast != null) {
        fast = fast.next;
        slow = slow.next;
    }
    slow.next = slow.next.next;
    return dummy.next;
}

8. Linked List Cycle II (LeetCode 142)

Medium
Input: head = [3,2,0,-4], pos = 1
Output: tail connects to node index 1

Detailed Approach: Use fast and slow pointers to detect a cycle. Once they meet, reset one pointer to the head and advance both one step at a time until they meet at the cycle start node.

public ListNode detectCycle(ListNode head) {
    ListNode slow = head, fast = head;
    boolean hasCycle = false;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) { hasCycle = true; break; }
    }
    if (!hasCycle) return null;
    slow = head;
    while (slow != fast) {
        slow = slow.next;
        fast = fast.next;
    }
    return slow;
}

9. Reorder List (LeetCode 143)

Medium
Input: [1,2,3,4]
Output: [1,4,2,3]

Detailed Approach: Split the list in half, reverse the second half, and merge the two halves alternately.

public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    ListNode slow = head, fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
    }
    ListNode prev = null, curr = slow.next;
    slow.next = null;
    while (curr != null) {
        ListNode nextTemp = curr.next;
        curr.next = prev;
        prev = curr;
        curr = nextTemp;
    }
    ListNode h1 = head, h2 = prev;
    while (h2 != null) {
        ListNode t1 = h1.next, t2 = h2.next;
        h1.next = h2;
        h2.next = t1;
        h1 = t1;
        h2 = t2;
    }
}

10. Intersection of Two Linked Lists (LeetCode 160)

Medium
Input: intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5]
Output: Reference of the node with value 8

Detailed Approach: Use two pointers traversing both lists. When pointer A reaches the end, redirect it to head B; when pointer B reaches the end, redirect it to head A. They will meet at the intersection.

public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    if (headA == null || headB == null) return null;
    ListNode a = headA, b = headB;
    while (a != b) {
        a = (a == null) ? headB : a.next;
        b = (b == null) ? headA : b.next;
    }
    return a;
}

Hard Level Challenges

11. Reverse Nodes in k-Group (LeetCode 25)

Hard
Input: head = [1,2,3,4,5], k = 2
Output: [2,1,4,3,5]

Detailed Approach: Check if there are at least `k` nodes remaining. If so, reverse the k-group iteratively and recursively link it to the result of the remaining sub-list.

public ListNode reverseKGroup(ListNode head, int k) {
    ListNode curr = head;
    int count = 0;
    while (curr != null && count < k) {
        curr = curr.next;
        count++;
    }
    if (count == k) {
        curr = reverseKGroup(curr, k);
        while (count-- > 0) {
            ListNode tmp = head.next;
            head.next = curr;
            curr = head;
            head = tmp;
        }
        head = curr;
    }
    return head;
}

12. Merge k Sorted Lists (LeetCode 23)

Hard
Input: lists = [[1,4,5],[1,3,4],[2,6]]
Output: [1,1,2,3,4,4,5,6]

Detailed Approach: Use a Min-Heap (`PriorityQueue`) to track the minimum current node across all `k` lists in $O(\log k)$ time per insertion/poll.

public ListNode mergeKLists(ListNode[] lists) {
    if (lists == null || lists.length == 0) return null;
    PriorityQueue<ListNode> minHeap = new PriorityQueue<>((a, b) -> a.val - b.val);
    for (ListNode list : lists) {
        if (list != null) minHeap.offer(list);
    }
    ListNode dummy = new ListNode(0), curr = dummy;
    while (!minHeap.isEmpty()) {
        ListNode smallest = minHeap.poll();
        curr.next = smallest;
        curr = curr.next;
        if (smallest.next != null) minHeap.offer(smallest.next);
    }
    return dummy.next;
}

13. Copy List with Random Pointer (LeetCode 138)

Hard
Input: head = [[7,null],[13,0],[11,4],[10,2],[1,0]]
Output: Deep copied linked list

Detailed Approach: Interleave cloned nodes right next to original nodes (`A -> A' -> B -> B'`), assign random pointers for clones, and then separate the two lists.

public Node copyRandomList(Node head) {
    if (head == null) return null;
    Node curr = head;
    while (curr != null) {
        Node clone = new Node(curr.val);
        clone.next = curr.next;
        curr.next = clone;
        curr = clone.next;
    }
    curr = head;
    while (curr != null) {
        if (curr.random != null) {
            curr.next.random = curr.random.next;
        }
        curr = curr.next.next;
    }
    curr = head;
    Node dummy = new Node(0), copyCurr = dummy;
    while (curr != null) {
        copyCurr.next = curr.next;
        copyCurr = copyCurr.next;
        curr.next = curr.next.next;
        curr = curr.next;
    }
    return dummy.next;
}
